Cenas de fundo da home (Saldo Zero)

Demo autônoma: public/scenes/demo.html (servir public/ por http, ex.: cd public && python3 -m http.server e abrir /scenes/demo.html; ?scene=0..3 fixa uma cena).

1. No <head> do game.html

<link rel="stylesheet" href="/scenes/home-scenes.css">

2. Atrás da home (o DESIGNER aplica desfoque/escurecimento no próprio container)

<div id="homeScenes" aria-hidden="true"></div>
/* CSS do DESIGNER, ex.: */
#homeScenes{filter:blur(2px) brightness(.8);transform:scale(1.04)}

O container precisa de um pai com position:relative (ou ocupar a tela com position:fixed; inset:0; z-index:0). O CSS das cenas já dá position:absolute; inset:0.

3. Antes de </body>

<script src="/scenes/home-scenes.js" defer></script>

Auto-inicia se #homeScenes existir. API opcional: HomeScenes.pause() ao entrar numa partida (congela animações e a troca), HomeScenes.resume() ao voltar à home, HomeScenes.show(i).

Comportamento

  • 4 SVGs (scene-jato|charutos|resort|fachada.svg) são buscados e injetados inline (animações CSS dentro de cada SVG; funcionam offline se estiverem no cache do SW).
  • Troca a cada 4 s com crossfade de 1,1 s; só a cena ativa anima.
  • Pausa com aba oculta, com HomeScenes.pause() e quando #homeScenes está com display:none.
  • prefers-reduced-motion: cena do jato estática, sem animação e sem alternância.

Mudanças necessárias em server.ts e public/sw.js (NÃO aplicadas aqui)

server.ts (const MIME): faltava css. Adicionar css: "text/css; charset=utf-8". svg e js já existem. Atenção: arquivos estáticos saem com cache-control: public, max-age=31536000, immutable; se as cenas forem alteradas depois, versionar a URL (ex.: ?v=2 nos links) ou mudar o nome.

public/sw.js (const SHELL): para funcionar offline desde a primeira visita, acrescentar '/scenes/home-scenes.css', '/scenes/home-scenes.js', '/scenes/scene-jato.svg', '/scenes/scene-charutos.svg', '/scenes/scene-resort.svg', '/scenes/scene-fachada.svg'. Sem isso, o handler existente (cache-first com preenchimento em runtime) guarda os arquivos após o primeiro acesso online.
